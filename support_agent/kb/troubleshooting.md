# Troubleshooting

Work through these in order for a customer reporting no signal or slow data. First rule out a suspended line and a known area outage (check line status); if either applies, handle that instead of device steps.

**No signal / no service**
1. Toggle airplane mode on for 10 seconds, then off.
2. Restart the device.
3. Reseat the SIM card (power off, remove SIM, reinsert).
4. Check for carrier settings / software updates.
If none resolve it after the line is confirmed active with no outage, escalate to technical support.

**Slow data**
1. Confirm the customer is not past their high-speed allowance — check data usage. After the allowance, speeds are throttled until the next cycle; the fix is an upgrade, not a repair.
2. If within allowance, restart the device and toggle airplane mode.
3. Check for an area outage.

**Hotspot not working**
- Basic 5GB has no hotspot. Plus and Premium include it. If on Basic, the fix is upgrading the plan.
